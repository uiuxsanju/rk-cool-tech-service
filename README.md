# RK Cool Tech Services – Next.js Website

SEO-optimised website built on the **Lovable design** (screenshot-scene-studio-54.lovable.app), with full service pages added.
Premium, SEO-optimised website for **RK Cool Tech Services**, an AC repair & home appliance service business in Visakhapatnam (Vizag).

**Stack:** Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Lucide React · Framer Motion · next/image · next/font (self-hosted Manrope + DM Sans)

## Photos & logo (important)
The real photos and logo come from the Lovable site. `scripts/fetch-images.mjs` runs automatically before `npm run dev` / `npm run build` (on Vercel too) and downloads them into `public/images/`:
`rk-cool-tech-logo.jpg, rk-hero.jpg, service-ac.jpg, service-fridge.jpg, service-washer.jpg, service-ro.jpg, service-geyser.jpg, service-electrical.jpg`.
- After the first local run, **commit `public/images/`** so the site no longer depends on the Lovable site.
- If a download fails, a placeholder illustration is used (the build never breaks), and it is retried next run.
- To use your own photos, just replace those files (same names) and delete `public/images/.fallback.json`.

## Run locally
```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start   # production check
```
Requires Node.js 20.9+.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. In Vercel, click **New Project** and import the repo. The Next.js framework is detected automatically.
3. In **Settings → Environment Variables**, add:
   - `NEXT_PUBLIC_SITE_URL` = `https://your-domain.com` (no trailing slash). Canonicals, sitemap, OG tags and JSON-LD all use it.
   - `NEXT_PUBLIC_GSC_VERIFICATION` = Google Search Console HTML-tag code (optional, add it when you have it)
4. Add the custom domain, then redeploy.

```
  site.css              Lovable design system (hero, service cards, reasons, brands, process, area, contact, footer) + service-page styles
  layout.tsx            Root layout, global metadata, fonts, header/footer, floating contact
  page.tsx              Homepage (13 sections in the required order)

  sitemap.ts            /sitemap.xml
  robots.ts             /robots.txt
  manifest.ts           /manifest.webmanifest
  not-found.tsx         404 page (noindex)
  icon.svg, apple-icon.png, fonts/
components/
  Header.tsx            Announcement bar, sticky header, Services dropdown, mobile menu (client)
  Footer.tsx            Footer with links to all 7 service pages
  Floating.tsx          Floating WhatsApp + Call (desktop) and sticky CALL NOW / WHATSAPP bar (mobile)
  blocks.tsx            ServiceCard, Reasons, Brands, Process, Area, FAQ, Contact, buttons, JsonLd
  EnquiryForm.tsx       Enquiry form → opens WhatsApp with details pre-filled (client)
  Reveal.tsx            Framer Motion scroll animation (respects reduced-motion)
  icons.tsx

  fetch-images.mjs      Downloads the Lovable photos/logo into public/images (with fallbacks)
lib/
  content.ts            ALL website text: services, FAQs, areas, brands
  site.ts               Business info, phone, WhatsApp helpers, SITE_URL
  schema.ts             JSON-LD builders (HVACBusiness, Service, FAQPage, BreadcrumbList, WebSite)
  types.ts
public/images/          WebP images, OG image, logo
```

## SEO checklist (verified on the production build)
- Unique `<title>` and meta description on every page (Metadata API, `generateMetadata`)
- Exactly one H1 per page, plus a proper H2/H3 hierarchy
- Canonical URLs, Open Graph and Twitter cards
- `sitemap.xml` and `robots.txt` generated by Next.js
- JSON-LD structured data with no fake ratings, reviews, street address or opening hours
- Breadcrumbs on service pages, descriptive internal links, related-services block
- `next/image` (AVIF/WebP, lazy by default, priority hero image, fixed sizes so there is no layout shift)
- Self-hosted fonts, Server Components by default, all pages statically pre-rendered
- All `tel:+919000626018` and `wa.me/919000626018` links work; each service has a pre-filled WhatsApp message
- No broken internal links; unknown URLs return a 404 page
