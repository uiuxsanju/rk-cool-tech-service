# Brand logos

`logos/` holds the logos shown in the auto-scrolling brands strip (homepage + service pages).
The list and order come from `BRANDS` in `lib/content.ts`.

To add a brand: put `logos/<slug>.webp` (or replace the file) and add `{ slug, name, w, h }` to `BRANDS`.
Brand names and logos are trademarks of their owners – used only to show which brands are serviced.
